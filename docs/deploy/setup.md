# Deploy setup (one-off, owner)

The compose files are generated by `aspire publish` in CI (`compose` artifact of a push to `main`) and never committed. Locally:

```sh
Deploy__Copy=Test Deploy__Pool=tank aspire publish --apphost src/KleinGeld.AppHost/KleinGeld.AppHost.csproj -o out/test
```

`Deploy__Copy` is `Production` (default) or `Test`; `Deploy__Pool` is the TrueNAS pool holding `kleingeld/`.

## GitHub

- Set the repository variable `TRUENAS_POOL` (Settings → Secrets and variables → Actions → Variables). The publish job fails without it.
- After the first push to `main`, make the `kleingeld-web` and `kleingeld-migrator` GHCR packages public (package settings → Change visibility), so TrueNAS pulls without credentials. CI keeps the last 10 versions of each.

## Datasets and ownership

Each copy lives under `/mnt/<pool>/kleingeld/{production,test}` with `secrets.env` (mode 600, from `docs/deploy/<copy>/secrets.env.example`) and `release.env` (`docs/deploy/release.env.example`).

| Folder | Container user | Command |
| --- | --- | --- |
| `postgres` | 999 (`postgres` in `postgres:18.3`; its entrypoint also fixes ownership when started as root) | `chown 999:999` |
| `keys` | 1654 (`APP_UID`, the .NET image's non-root `app` user) | `chown 1654:1654` |
| `azurite` (Test) | 0 (root) | none needed |

## Ports

All bound to 127.0.0.1; Tailscale fronts them (Funnel for Production, `serve` for Test only).

| Copy | Service | Host port |
| --- | --- | --- |
| Production | web | 8080 |
| Test | web | 8081 |
| Test | MailPit inbox | 8025 |
| Test | Azurite blobs | 10000 |
